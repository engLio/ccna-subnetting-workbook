# CCNA Subnetting Practice Workbook

A free, 18-page IPv4 subnetting workbook for CCNA and Network+ candidates: a 5-step method, worked examples, 50 practice questions and a full answer key.

**[Download the workbook (PDF)](Subnetting_Practice_Workbook.pdf)**

## What's inside the workbook

| Part | Content |
|---|---|
| 1. Foundations | Binary, IPv4 anatomy, classes, private ranges, subnet masks and CIDR |
| 2. The Magic Number Method | 5-step procedure, 5 worked examples, equal-size subnetting, VLSM walkthrough |
| 3. Practice Sets | 50 questions in 5 sets (A to E) and a VLSM design challenge, with write-in tables |
| 4. Answer Key | Every answer with the working shown |
| 5. Exam Toolkit | 8 common mistakes, exam-day tips, a 7-day study plan |
| Appendix | One-page quick-reference sheet |

Every answer in the key was generated and cross-checked with Python's `ipaddress` module.

## How to use it

1. Read Parts 1 and 2 and redo each worked example on paper.
2. Attempt Sets A to E **without a calculator**.
3. Check Part 4 and find the exact step where any mistake happened.
4. Redo missed questions after 48 hours.
5. Target: under 60 seconds per Set B question before the exam.
